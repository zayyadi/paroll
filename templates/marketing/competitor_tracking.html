How to keep this current

  • Edit vendor rows in Django admin → Marketing → Competitors: update pricing, flip feature values, and set last_verified to today.
  • Records with last_verified older than 90 days (or missing) are flagged stale here.
  • Add capabilities to FEATURE_CATALOG in marketing/models.py; new rows appear in the matrix automatically.
  • Capability values: yes / no / partial / unknown. Use unknown rather than guessing; the matrix treats it as unverified.
