# Dashboard & Navigation Revamp Plan

**Date:** June 11, 2026
**Scope:** All dashboards (admin, HR, user) + sidebar navigation + inventory/accounting dashboards
**Goal:** Model after real ERP/HRMS apps (BambooHR, Gusto, Workday) with proper module links

---

## Current State Analysis

### Problems:
1. **Admin Dashboard**: Generic "System Health" widget, no accounting/inventory links, no payroll summary
2. **HR Dashboard**: Missing quick links to transfers, promotions, offboarding, contracts, schedules, stock counts
3. **User Dashboard**: Missing links to attendance, documents, surveys, learning, contracts
4. **Sidebar Navigation**: Flat list with no grouping — admin/staff see 15+ flat links, no visual hierarchy
5. **Inventory Dashboard**: Minimal — just stats + low stock, no quick actions
6. **Accounting Dashboard**: Good KPIs but no quick links to journals, reports, reconciliation
7. **No module-level navigation** — clicking "Accounting" takes you to dashboard but no sidebar nav within accounting

---

### Phase 2: Admin Dashboard Revamp

**File:** `templates/dashboard_admin_new.html`

Add real ERP-style sections:
- **Quick Actions Grid**: Add Employee, Process Payroll, Create Journal, Stock Count, Run Report
- **Payroll Summary Card**: Active employees, pending payroll, last run date
- **Accounting Summary Card**: Total revenue, expenses, pending journals, bank balance
- **Inventory Summary Card**: Items, low stock alerts, pending POs, pending invoices
- **Recent Activity Feed**: Consolidated from payroll + accounting + inventory

### Phase 3: HR Dashboard Revamp

**File:** `templates/employee/dashboard_new.html`

Add quick action cards for:
- People (list, add, transfers, promotions, offboarding)
- Leave management (approve, calendar, policies)
- Payroll (payslips, payslip email, bank reports)
- Performance (appraisals, reviews)
- Hiring (pipeline, requisitions)
- Contracts & Documents
- Reports (PAYE, pension, NHF, NHIS)

### Phase 4: User Dashboard Revamp

### Phase 5: Inventory Dashboard Revamp

### Phase 6: Accounting Dashboard Revamp
